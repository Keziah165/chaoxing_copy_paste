# 到梦空间 · 成长记录补录批量填表助手

一个运行在浏览器里的油猴/控制台脚本，用来替代「到梦空间学校管理端」中**已损坏的批量导入功能**：自动读取 Excel，逐行填入「成长记录补录」弹窗，由人工核对后点击「确认」，再自动处理下一条。

脚本只负责**填表**，不会替你点击「确认」，是否加分由你把关。

## 适用场景

- 到梦空间学校管理端的「批量补录」功能异常，无法正常导入；
- 需要批量补录学生第二课堂成长记录，且希望逐条人工审核；
- 数据已按官方模板整理为 `.xlsx` 文件。

## 功能特性

- 读取 Excel（`.xlsx`），按表头自动识别列，从包含「学号」的表头行之后解析数据；
- 跳过说明行（学号非纯数字的行自动忽略），示范行可在列表中手动取消勾选；
- 逐行自动填入「成长记录补录」弹窗的全部字段：学号、参与时间、活动级别、一级/二级分类、记录内容、奖项、学分类型与发放学分值；
- 填完一行即暂停，等待人工核对并点击「确认」，检测到弹窗关闭后自动进入下一条；
- 支持「开始 / 继续」「暂停」「跳过当前」「重置进度」，可在列表中点击任意行跳转；
- 实时日志，便于排查字段未写入等问题；
- 兼容多种日期格式：`2026/11/2`、`2026-11-2`、`2026年11月2日`、`11/2/26`、Excel 日期序列号等，统一转换为 `yyyy-MM-dd`。

## Excel 字段对应关系

| Excel 列名 | 填入表单字段 | 说明 |
| --- | --- | --- |
| 学号 | 发放用户学号 | 纯数字行才会被当作数据 |
| 姓名 | （仅列表展示，不填入表单） | 供核对身份 |
| 开始时间 | 参与时间 - 开始时间 | 必填 |
| 结束时间 | 参与时间 - 结束时间 | 可为空 |
| 活动等级 | 活动级别 | 下拉自动匹配 |
| 活动一级分类 | 活动一级分类 | 下拉自动匹配，选完会等待二级分类联动加载 |
| 活动二级分类 | 活动二级分类 | 下拉自动匹配 |
| 内容 | 记录内容 | 不超过 30 字 |
| 奖项内容 | 奖项 | 多个奖项用「、」分隔，自动点「新增」分行填入 |
| 学分类型 | 学分（下拉） | 下拉自动匹配 |
| 发放学分值 | 学分（数字输入框） | 填入数值 |

> 下拉选项的文字必须与 Excel 中的值**完全一致**，否则会报「下拉中未找到选项」。

## 安装与运行

### 方式一：Tampermonkey / 脚本猫（推荐，一次安装长期有效）

1. 浏览器安装 Tampermonkey 或脚本猫扩展；
2. 打开本仓库的 `daomeng-bulu.user.js`，全选复制；
3. 在扩展中「添加新脚本」，粘贴覆盖默认内容，保存；
4. 打开到梦空间学校管理端「成长记录管理」页面，右上角会出现「批量补录助手」面板。

> 若脚本猫保存时报「MetaData 信息错误」，请先清空编辑器默认模板再粘贴，或直接使用「导入」功能导入 `.user.js` 文件。

### 方式二：浏览器控制台（临时，无需安装扩展）

1. 打开到梦空间「成长记录管理」页面；
2. 按 `F12` 打开开发者工具，切换到 Console（控制台）；
3. 把 `daomeng-bulu.user.js` 的全部内容粘贴进去回车；
4. 右上角出现「批量补录助手」面板即可使用。

> 控制台方式在刷新页面后需要重新粘贴。

## 使用流程

1. 点击面板中的「选择 Excel 文件」，选择你的 `.xlsx`；
2. 下方列表会列出解析出的数据行，**取消勾选示范行**（如 `100001`、`1000003`）；
3. 点击「开始 / 继续」，脚本自动点开「成长记录补录」弹窗并填入当前行；
4. 核对无误后，手动点击弹窗里的「确认」；
5. 脚本检测到弹窗关闭后，自动处理下一条；
6. 某条需跳过可点「跳过当前」；误点「取消」或关闭弹窗会自动暂停，再点「开始 / 继续」即可。

## 注意事项

- 脚本运行时需保持该页面标签页处于前台（部分浏览器会限制后台标签页的脚本执行）；
- 首次使用建议先用 1–2 条试跑，确认下拉选项与日期格式匹配正确后再批量处理；
- 若某字段未写入，查看面板「日志」中的提示（如 `⚠ 开始时间未写入`），据此调整 Excel 数据格式；
- 「记录内容」超过 30 字会被表单截断，请在 Excel 中预先控制长度。
